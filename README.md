# Nexus AI
Déposer index.html à la racine d’un dépôt GitHub, puis Settings > Pages > Deploy from a branch > main / (root). Ouvrir l’URL HTTPS fournie. Pas de compilation ni de clé API.
Connexion via la fenêtre Puter, choisir Google si proposé. Sur iPhone utiliser Safari normal, conserver les données du site et la même URL. Les conversations sont isolées par compte et sauvegardées via Puter KV, avec copie locale. Synchroniser avant de changer d’appareil ; éviter les modifications simultanées (dernière version par conversation, sans transaction). L’aperçu du studio est isolé et ne peut pas authentifier Puter ; tester le site exporté sur sa propre URL HTTPS. Le studio exporte un fichier autonome, pas un projet backend. Les crédits IA sont ceux de votre compte Puter.
